# Imágenes del template

Coloca aquí imágenes reales autorizadas de la clínica antes de publicar una versión para cliente.

Reemplazos sugeridos:

- Hero clinic photo.
- Team photo.
- Clinic interior.
- Building/entrance.
- Treatment image.

Reglas:

- No usar fotos falsas que parezcan pertenecer a la clínica.
- Comprimir imágenes antes de subirlas.
- Usar `object-fit` con cuidado para no cortar rostros.
- Agregar `alt` en español.
- Usar `loading="lazy"` en imágenes debajo del primer viewport.
